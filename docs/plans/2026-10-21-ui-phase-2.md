## Design

Retain Manrope, warm white and forest green. Use generous spacing, a clear date hierarchy, useful access badges, adaptive multi-column desktop catalogues and one-column phone layouts. Activity details and request forms open as familiar bottom sheets with visible close/back controls. Immediate press feedback uses the existing interruptible, critically damped buttons; sheets respect reduced motion and solid/high-contrast navigation preferences. Labels and status feedback support BM/EN, keyboard use and larger text.
